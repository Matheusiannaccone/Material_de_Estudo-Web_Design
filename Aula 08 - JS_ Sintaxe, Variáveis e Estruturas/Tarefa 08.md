# Instruções da Tarefa
- Crie um projeto e utilize os arquivos index.html, style.css e script.js incluindo o JS de forma Externa ao HTML, através da tag `<script src>`.
- Adicione pelo menos 5 funcionalidades em JavaScript, seguindo os exemplos apresentados em aula.
- Adicione um arquivo Readme.md no projeto, descrevendo as funcionalidades implementadas. O Arquivo deve conter pelo menos 100 linhas.

- Em seguida, utilize o Git no VS Code para integrar o projeto a um repositório no GitHub, inicializando o versionamento e realizando a publicação do código.
- Realize melhorias no projeto e a adição de novos recursos, garantindo que o index.html tenha mais de 500 linhas, o style.css tenha mais de 400 linhas e o script.js tenha mais de 300 linhas.
- Por fim, comente todo o código explicando o que cada parte faz. Documente tudo em um arquivo com o código, repositório e prints e realize o envio na plataforma CANVAS.
