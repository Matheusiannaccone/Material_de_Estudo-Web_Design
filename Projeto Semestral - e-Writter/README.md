## Sobre o projeto

O **e-Writter** é uma plataforma Web de escrita, publicação e leitura de obras literárias, desenvolvida como projeto semestral da disciplina de Web Design, do curso de Engenharia de Computação do Centro Universitário Facens.

O projeto tem como objetivo proporcionar um ambiente digital no qual os usuários possam criar, organizar, publicar e consumir conteúdos literários estruturados em obras e capítulos.

A aplicação foi desenvolvida colaborativamente ao longo do segundo semestre de 2026, integrando os conhecimentos adquiridos durante a disciplina e conceitos complementares de desenvolvimento Web, arquitetura de software, banco de dados e segurança.

## Objetivos

- Aplicar os conhecimentos adquiridos durante a disciplina de Web Design.
- Desenvolver uma aplicação Web funcional, responsiva e interativa.
- Integrar a interface com serviços de autenticação e banco de dados.
- Aplicar boas práticas de organização e arquitetura de software.
- Utilizar ferramentas de controle de versões e desenvolvimento colaborativo.
- Documentar os requisitos, decisões técnicas e resultados do projeto.

## Funcionalidades desenvolvidas

- Cadastro e autenticação de usuários.
- Recuperação e redefinição de senha.
- Gerenciamento de perfil.
- Criação e edição de obras literárias.
- Classificação de obras por gêneros.
- Criação e edição de capítulos.
- Publicação e retirada de publicação de conteúdos.
- Catálogo público de obras.
- Interface de leitura de capítulos.
- Biblioteca pessoal de favoritos.
- Interfaces responsivas.
