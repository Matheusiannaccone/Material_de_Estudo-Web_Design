## Sobre o repositório

Este repositório foi desenvolvido como atividade final da disciplina de **Web Design**, do curso de Engenharia de Computação do Centro Universitário Facens, durante o segundo semestre de 2026.

Seu objetivo é reunir, centralizar e organizar os materiais didáticos disponibilizados ao longo do semestre, juntamente com os enunciados das atividades propostas e os respectivos relatórios técnicos desenvolvidos.

O conteúdo está organizado sequencialmente por aula, respeitando a ordem de apresentação dos assuntos durante a disciplina, permitindo acompanhar a evolução do aprendizado e facilitando a consulta e a revisão dos conceitos estudados.

Além de atender à proposta da atividade final, este repositório busca servir como uma fonte de consulta para estudos futuros e para a aplicação dos conhecimentos adquiridos em novos projetos de desenvolvimento Web.

O repositório também reúne os materiais acadêmicos relacionados ao projeto semestral e-Writter, desenvolvido em equipe como aplicação integrada dos conhecimentos adquiridos durante a disciplina.

## Organização dos materiais

Cada aula possui um diretório próprio, identificado pelo seu número e pelo assunto abordado.

Os diretórios seguem uma estrutura padronizada, composta pelos seguintes tipos de arquivos, conforme a disponibilidade e a natureza de cada atividade:

| Arquivo | Descrição |
|---|---|
| `Conteúdo_da_Aula_XX.pdf` | Material didático disponibilizado pelo professor, contendo os conceitos teóricos e exemplos apresentados em aula. |
| `Tarefa XX.md` | Enunciado da atividade proposta, contendo as instruções, os requisitos e, quando aplicável, o link para o código desenvolvido. |
| `Relatório Técnico - XX.pdf` | Documentação da atividade realizada, apresentando o desenvolvimento, os recursos implementados e os resultados obtidos. |

Essa organização permite consultar tanto os fundamentos teóricos quanto sua aplicação prática, relacionando diretamente o conteúdo apresentado em aula com as atividades desenvolvidas.

A primeira aula não possui relatório técnico, pois sua atividade foi destinada à formação dos grupos de trabalho da disciplina.

## Tecnologias e ferramentas

### HTML5

- Estruturação de documentos Web.
- Elementos e tags semânticas.
- Formatação de textos.
- Links e navegação.
- Imagens, vídeos e áudios.
- Listas, tabelas e formulários.
- Técnicas de otimização para mecanismos de busca (SEO).

### CSS3

- Seletores e propriedades.
- Cores e tipografia.
- Estilização de elementos.
- Organização de layouts.
- Box Model.
- Flexbox.
- Responsividade.

### JavaScript

- Sintaxe e fundamentos da linguagem.
- Variáveis e tipos de dados.
- Operadores e estruturas de controle.
- Funções.
- Implementação de funcionalidades interativas em páginas Web.

### Git e GitHub

- Criação e gerenciamento de repositórios.
- Controle de versões.
- Registro de alterações por meio de commits.
- Utilização de branches e tags.
- Versionamento semântico.
- Desenvolvimento colaborativo.
- Documentação de projetos com Markdown.

### Visual Studio Code

- Criação e edição de arquivos de código.
- Organização de projetos Web.
- Integração com Git e GitHub.
- Desenvolvimento e manutenção de aplicações Web.

## Projetos desenvolvidos

Durante o semestre, foram desenvolvidas atividades práticas com o objetivo de aplicar os conhecimentos adquiridos em aula.

Os códigos-fonte dessas atividades estão vinculados aos seus respectivos arquivos de instruções, permitindo acessar os repositórios originais e consultar as implementações realizadas.

A separação entre os materiais de estudo e os repositórios de desenvolvimento permite preservar o histórico original de versionamento dos projetos, evitando a duplicação dos códigos-fonte.

Os relatórios técnicos disponíveis neste repositório complementam essas implementações, documentando o processo de desenvolvimento e os resultados alcançados.

## Projeto semestral — e-Writter

Como parte das atividades acadêmicas da disciplina, foi desenvolvido o **e-Writter**, uma plataforma Web destinada à escrita, publicação e leitura de obras literárias.

O projeto integra os conhecimentos adquiridos ao longo do semestre, utilizando HTML, CSS e JavaScript, além de tecnologias complementares para autenticação, armazenamento de dados e segurança.

| Recurso | Acesso |
|---|---|
| Materiais acadêmicos do projeto | [Acessar](./Projeto%20Semestral%20-%20e-Writter/) |
| Repositório oficial | [GitHub](https://github.com/Matheusiannaccone/e-Writter) |
| Documentação técnica | [Consultar documentação](https://github.com/Matheusiannaccone/e-Writter/tree/main/docs) |

Os materiais referentes às avaliações acadêmicas estão disponíveis neste repositório, enquanto o código-fonte e o histórico de desenvolvimento são mantidos no repositório oficial do projeto.
