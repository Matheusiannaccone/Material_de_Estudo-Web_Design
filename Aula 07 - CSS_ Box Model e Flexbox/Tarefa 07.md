Instruções da Tarefa
- Crie um projeto e utilize os arquivos index.html e style.css, incluindo o CSS de forma Externa ao HTML, através da tag <link>.
- Adicione 20 elementos e atribua valores em todas as propriedades de de Content, Padding, Border e Margin.
- Em seguida, adicione 20 propriedades de Flexbox para manipular os elementos e organizá-los de forma responsiva.
- Em seguida, utilize o Git no VS Code para integrar o projeto a um repositório no GitHub, inicializando o versionamento e realizando a publicação do código.
- Realize melhorias no projeto e a adição de novos recursos, garantindo que o index.html tenha mais de 400 linhas e o style.css tenha mais de 300 linhas.
- Por fim, comente todo o código explicando o que cada parte faz. Documente tudo em um arquivo com o código, repositório e prints e realize o envio na plataforma CANVAS.
